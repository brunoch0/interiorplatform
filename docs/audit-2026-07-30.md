# 전면 점검 — 2026-07-30 (기능 / SEO / GA4·UTM)

기능은 브라우저로 실제 조작, SEO·GA4는 코드 감사 + 프로덕션 응답으로 검증. 아래 "고친 것"은 전부 프로덕션에서 재확인됨.

## 🔴 고친 것 — 치명적

| 문제 | 영향 | 조치 |
|---|---|---|
| **업체 상세 649페이지 전부 500 에러** | 콜드메일 30통이 링크한 바로 그 URL. 최소 6시간 이상 다운 | `companyPhotoUrl`/`mapsUrl`이 `"use client"` 파일에 있어 서버 렌더 크래시 → `lib/site.ts`로 이동 |
| **GA4가 프로덕션에서 미작동** (내가 만든 회귀) | 스크립트 URL이 client-reference 스텁으로 깨져 이벤트 0건 | `GA_ID`를 `lib/site.ts`로 이동. 위와 동일한 근본 원인 |
| **git push로 배포가 안 걸림** | 수정이 반영되지 않은 채 6시간 방치 | `npx vercel deploy --prod`로 수동 배포. **원인 미해결 — 아래 백로그 P0** |

| 클라이언트 이동 시 GA4 page_view 완전 유실 | 내부 이동 전체가 미집계 → 세션 경로·이탈 분석 불가 | `send_page_view:false` + `PageViewTracker` 수동 발송 |
| 전환 이벤트 0개 | 견적·상담·입찰·클레임 = 사업 전체가 미측정 | 6종 이벤트 추가 (아래) |

## 🟠 고친 것 — 높음

- **홈·/companies·/quote가 같은 title/description 공유** → 각각 고유 메타데이터 + canonical
- **title 전부 60자 초과** (템플릿이 17자 추가) → `%s · Onepass`로 축소
- **데모/목업 14개 라우트가 색인 가능** (가짜 라이선스·에스크로 표시 = 신뢰 리스크) → noindex + robots 차단 + 사이트맵에서 `/onboarding` 제거
- **`/admin` 링크가 모든 공개 페이지 헤더에 노출** → 관리자 화면에서만 표시
- **Organization·WebSite 스키마 없음** → 루트에 추가 (브랜드 엔티티 인식)
- **OG 이미지에 옛 vercel 도메인 표기** → 실도메인
- **콜드메일 링크 UTM 없음** → 배치1(30통)은 (direct)로 유실 확정, 배치2부터 태깅
